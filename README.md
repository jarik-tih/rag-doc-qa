# QA-system (RAG-pipeline)
## Идея проекта:
Сервис, который принимает PDF документы, индексирует их и отвечает на вопросы, на основе содержимого.
В моем проекте это файлы c arxiv по научным статьям по ML-engineering.
## Архитектура проекта
Архитектура проекта состоит app-логики того как все работает: ingestion-отвечает за chunking,
embeddings-за embedding, и т.д. 
В дальнейшем собираюсь обернуть приложение в FastAPI.

Scripts-отвечает за выполнение самой логики приложения, описанной в app.

Data-отвечает за файлы, которые необработаны, прошли через chunking, embeddings.
